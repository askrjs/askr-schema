# Schema hardening for 0.5.0

Executed 2026-10-09. Preparation retains version 0.4.1; it does not certify the
coordinated 0.5.0 package set or publication.

The baseline `npm run check` passed 31 cases and the existing type, build,
packed scalar/combinator and publint checks. Assertion inspection confirmed
existing Unicode/format/numeric boundaries, prototype-safe object/record keys,
stable paths, immutable deterministic projections, optional/nullable ordering,
uniqueItems depth/cycle handling and strict-object intersection projection
parity. New cases extend those contracts rather than replacing them.

## Executed boundary probes

Substituting the original implementation from develop
`46596a7` into the prepared barrel produces **26 failures and 4 passes** among
30 hardening probes. The four passing characterizations cover two malformed
regular expressions with recovery, undefined optional/nullable properties and
128-level eager validation with a complete stable issue path. All 30 pass with
the fixes.

| Boundary                                  | Outcome and ownership                                                                                                                                                                                                                                                                  |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Mutated constructor options               | Snapshot string, number, array and object options so runtime behavior cannot change after a frozen projection is emitted. Four confirmed regressions, cross-checked with Ajv.                                                                                                          |
| Mutated enum/declaration inputs           | Snapshot enum members and object declarations; later changes cannot create values or keys absent from the projection. Two confirmed regressions.                                                                                                                                       |
| Empty combinators                         | Reject empty oneOf/anyOf/allOf before emitting invalid JSON Schema; valid construction and parsing recover. Three confirmed regressions.                                                                                                                                               |
| Non-finite/duplicate literals             | Reject NaN/infinite enum and literal members and duplicate enums; distinct primitive kinds remain distinct. Four confirmed regressions.                                                                                                                                                |
| Invalid constraints                       | Reject negative/fractional/non-finite counts, non-finite numeric limits, nonpositive multipleOf and non-string patterns with constructor-specific TypeErrors. Seven confirmed regression cases.                                                                                        |
| Cyclic/deep projections                   | Active-path tracking rejects cycles with guidance to use $ref, permits shared references, and rejects projection object/array depth above 256 before native stack failure. Depth 256 passes; 257 rejects. Two confirmed regressions.                                                   |
| Declared size bounds                      | maxItems/maxProperties return the root too_big issue before child parsing. A 100,000-item oversized array invokes no child parser; a following bounded input parses normally. Oversized objects similarly skip declared/additional parsers. Two confirmed regressions.                 |
| Sparse/inherited array slots              | Validate every slot as its own value or undefined, retaining the exact index path; inherited entries cannot satisfy an absent slot. Two confirmed regressions.                                                                                                                         |
| Existing modifier/pattern/depth contracts | Malformed regex diagnostics remain SyntaxErrors with subsequent recovery; undefined optional fields normalize to omission in both nullable wrapper orders. A 128-level eager declaration validates good data and reports the entire invalid leaf path. Four passing characterizations. |

Declared size checks now stop child work as soon as the input exceeds the
author's explicit bound. This also changes oversized-input diagnostics to the
single root size issue instead of collecting arbitrary child errors. No cache,
fallback validator, public configuration or performance claim is introduced.
Legibility cost is none: bounds and child validation remain in the same parser.

Projection depth counts nested object/array containers, including metadata and
examples. It is a private resource boundary, not a recursive-schema discovery
feature. Eager schema builders still reject incomplete recursive declarations.
`raw()` callers own their manual validator's recursion, side effects and
resource limits. Unbounded arrays/records intentionally have no inferred
application limit; authors should declare maxItems/maxProperties where needed.

## Projection and package qualification

A separate 24-case matrix checks the exact 23-member builder namespace and
compares each builder with Ajv draft 2020-12 on accepted/rejected JSON-domain
values. It covers type, numeric/string/size/unique constraints, records,
modifiers, combinators and a caller-owned raw integer parser. Format validation
is disabled in this matrix: the existing explicit format algorithms and
adversarial values are exercised separately. Undefined optional values are
tested as JavaScript property semantics rather than JSON values.

`npm run test:packed` installs a real tarball into a fresh consumer, preserves
the existing scalar/canonicalization/allOf checks, and verifies the two export
map keys, one runtime namespace, all seven declaration exports, fourteen removed
imports, required/optional inference and private subpath rejection. npm commands
run through Node's JavaScript CLI so the probe executes on Windows. Ordinary
three-OS CI now runs packed checks and uploads implementation coverage.

`npm run check` on Node 24.21.0 passes **85 unit cases**, formatting, lint/types,
V8 coverage, built declaration fixtures, build, real packed consumer, publint
and pack contents. Compatible tooling updates leave `npm audit` at zero findings.
Coverage includes all production source and excludes test files:

| Measure    | Executed counters | Coverage |
| ---------- | ----------------- | -------- |
| Lines      | 332/334           | 99.40%   |
| Statements | 367/376           | 97.60%   |
| Functions  | 87/87             | 100%     |
| Branches   | 343/352           | 97.44%   |

The pure root barrel has no executable counters. JSON/HTML reports preserve
remaining defensive alternatives; coverage is not proof for arbitrary raw
parsers, proxy/accessor side effects or every possible JSON Schema keyword.

Fresh packed native ESM was served directly over local HTTP and executed in
Chromium, Firefox and WebKit. Eight cases per engine cover option snapshots,
declaration/enum snapshots, invalid definitions, projection cycles/depth/shared
references, oversized inputs and recovery, sparse/inherited slots, 128-level
issue paths and modifier/strict-object composition. **All 24 candidate cases
pass.** Registry 0.4.1 fails the first six probes in every engine (**18 failures**)
and passes the last two characterizations (**6 passes**). This checks browser
semantics, not a throughput or application capacity claim. The fixture, artifact
hashes and per-case results are retained in the release evidence directory.

The complete candidate package set and website API generation remain separate
release acceptance work.
